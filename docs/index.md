# aturfile

A fast file manager and disk cleanup for macOS, built with Rust and GPUI.

- Browse in List, Columns or Icons, with tabs and a preview pane.
- Find any file in your home folder with ⌘K.
- See what fills your disk and clear caches and build leftovers safely.

Free and open source ([GPL-3.0](https://github.com/dzulfikar08/aturfile)). aturfile Pro on the Mac App Store adds more than one tab and one-click trash for Clean Up.
